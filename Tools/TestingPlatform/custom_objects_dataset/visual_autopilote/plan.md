Максимальні положення керуючих поверхонь
| Поверхня         | Максимум в один бік | Максимум у другий бік |
| ---------------- | ------------------: | --------------------: |
| **Елерон**       |       **20° вверх** |          **15° вниз** |
| **Руль висоти**  |       **28° вверх** |          **23° вниз** |
| **Руль напряму** |      **≈16° вліво** |       **≈16° вправо** |
| **Закрилки**     |                  0° |                   40° |


Крутий швидкий розворот у напрямку цілі:
| Нахил            |      Елерони |       Руль висоти | Руль напряму |                     Тяга |
| ---------------- | -----------: | ----------------: | -----------: | -----------------------: |
| 60°              |            0 |       **+40–50%** |            0 |                     ~85% |
Руль висоти тут використовується вже після нахилу. Не для підйома літака вгору, а для швидкого розвороту
